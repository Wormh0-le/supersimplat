# AI Select experiments

This directory contains disposable investigation and validation tooling for AI Select.

## Layout

- `04c/` — SAM 3 Image migration cross-checks and repro probes.
- `benchmarks/` — executable benchmark harnesses.
- `browser-validation/` — executable browser/GPU validation harnesses.

Durable contracts, mappings, benchmark results and walkthrough records belong under `docs/ai-select/`.
