# AI Select Context Amendment 002 — Seed, discovery, and depth

Status: **current vocabulary overlay**  
Authority: Final Spec v2.0 Amendment 002 and ADR 0023

This file temporarily overrides conflicting definitions in root `CONTEXT.md`. Fold these terms into the root glossary during a later controlled consolidation, then delete this overlay and the superseded definitions together.

**Contribution-Weighted Expected Depth (CWED)**  
A Companion-internal `alpha × incoming-transmittance` weighted projection-depth statistic used as a calibrated feature. It is not first-hit depth, authoritative visible-surface depth, ownership, or a Browser protocol artifact.

**Conservative Seed Support**  
A high-precision, deliberately incomplete bootstrap prior derived after Anchor confirmation. Seed may initialize Core and early framing, but it never hard-bounds discovery, Evidence, Candidate membership, or Native Selection.

**S0 Seed**  
The shadow seed variant using semantic P/N/V support, valid Visible Mass, conflict checks, and scale-aware connectivity without a depth-consistency feature.

**S1 Seed**  
The shadow seed variant that adds a soft Gaussian-center depth-consistency feature using CWED quality and Gaussian scale. Failure of this feature does not permanently remove plausible support from discovery.

**Core Target Set**  
The current high-confidence target support used by Core Observation Coverage. It may expand without shrinking inside one stable input revision; an authoritative input revision may rotate and rebuild Core.

**Discovery Envelope**  
A seed-independent, deliberately broader target-local scope in which additional target support may be discovered. It is not ownership and may include background.

**Discovery Frontier**  
Reversible unresolved support inside the Discovery Envelope but outside Core. Frontier may grow, shrink, be rejected, or be promoted into Core; it is never directly applied as Candidate membership.

**Frontier Debt**  
A versioned measure of unresolved, potentially valuable Discovery Frontier support. It is distinct from Core Observation Coverage and is one input to readiness/continued-acquisition decisions.

**Depth-classified Negative Evidence (experimental)**  
A nonblocking benchmark hypothesis that divides Negative contribution by geometric depth relation. Current production retains one Negative Mass channel unless a later calibrated promotion explicitly changes schema and production identity.
