# AI Select Context Amendment 004 — Consensus Readout and Reliability

Status: **current vocabulary overlay**  
Authority: Final Spec v2.0 Amendment 004 / ADR 0025

This file temporarily overrides conflicting or incomplete root `CONTEXT.md` definitions until one controlled glossary consolidation.

## Consensus Readout

A Companion-internal same-decision projection of lagged q+s state under one View. It emits semantic moments for Reliability and diagnostics; it is not a Browser artifact, visibility authority, Candidate, or Mask.

## Support-aware Membership

The internal value `q̃ = 0.5 + s(q - 0.5)`. Low support contracts membership tendency toward neutral instead of allowing an unsupported extreme q to appear confident.

## Semantic Scope Mass

Accepted `alpha × incoming transmittance` contribution from frozen Core, Discovery Frontier, and Context scope. Render-only and Out-of-Scope Gaussians still occlude but do not contribute semantic moments.

## Consensus Knownness

The readout ratio of support-weighted semantic mass to semantic-scope mass. It indicates whether a pixel comparison is supported; it is not observation visibility or calibrated confidence.

## Core Fraction

The fraction of semantic-scope mass contributed by frozen Core Target support in one pixel.

## Frontier Fraction

The fraction of semantic-scope mass contributed by frozen Discovery Frontier support in one pixel.

## Trusted Comparison Support

A valid readout location with enough semantic-scope mass and knownness to evaluate Stable Mask disagreement. Insufficient support yields neutral Reliability rather than a penalty.

## Positive Frontier Protection

A bounded reduction of positive-interior disagreement when lagged consensus exposes substantial Frontier or weakly known support. It protects newly revealed target foreground from confirmation-bias punishment.

## Regional Reliability Residual

A view-level disagreement assembled from separately normalized Strong Positive Interior, Local Negative Context Ring, and optionally low-weight Boundary Band residuals. Far Neutral does not participate.

## Leave-one-out Reliability Reference

An offline benchmark that evaluates one View against consensus recomputed without that View. It measures self-influence and is not the production Reliability path.
