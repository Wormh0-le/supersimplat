# AI Select Context Amendment 007 — View Utility Probe

Status: current vocabulary overlay  
Supersedes conflicting View Utility wording in root `CONTEXT.md` until controlled glossary consolidation.

## View Utility

The prospective, versioned value assigned to one feasible candidate CameraBinding. It is distinct from realized Observation Coverage, structured Frontier Debt, Lift Readiness, and Candidate publication.

## Layered Candidate Pool

A deterministic finite set composed of carried-over hint offsets, a sparse target-scope shell, and bounded Debt-targeted cameras. Every candidate has a stable identity and source layer.

## Geometric Pruning

A cheap deterministic stage that rejects clearly infeasible or dominated cameras using projection, framing, distance, frustum, and duplication approximations. It is not occlusion or Evidence authority.

## ViewUtilityProbe

A Companion-local, low-resolution, complete-occlusion-aware raster probe applied only to a deterministic shortlist. It predicts Core gain, component Frontier/Debt reduction, Uncertain resolution, duplication, and deterministic cost. It does not produce RGB, Mask, P/N/V, Coverage, Readiness, or Candidate artifacts.

## Deterministic Cost Unit

A versioned estimate derived from declared scene/camera/work dimensions. Transient wall-clock, GPU occupancy, and cache hit state are not canonical ranking inputs.

## Realized Gain Record

The comparison between a selected View's prospective prediction and its later realized Coverage, Debt, Uncertain, Scope, and Candidate outcomes. It is calibration evidence, not an observation authority.
