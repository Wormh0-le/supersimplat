主要 tradeoff

选择 获得 代价 / 边界
每 Gaussian 取最大 V 重复 View 无法刷高覆盖率，尺度直观。 多个弱视角的互补累积不会提升单点覆盖；后续校准可能采用更丰富但仍防重复的聚合。
最大方向夹角 简单、稳定、容易解释，且与 View 数量解耦。 不能完整描述球面分布；三个视角是否均匀并不会比最佳一对得到更多奖励。
低成本诊断只做早期信号 正式 Evidence 缺失时仍能保守提示，不混淆 P/N/V。 界面可能长时间显示 pending，而不是一个看似精确但不可信的百分比。
独立 readiness artifact/store 严格绑定身份，失败保留旧结果；不耦合 Candidate 或原生选择。 当前没有新增传输路由；生产实时发布要由后续 Evidence/Re-Lift 垂直切片接入。
诚实的完成边界：这是基于 complete-Contributor reference aggregation 的 Ticket 13 参考/校准闭环。它完成算法、跨运行时契约、浏览器状态与展示，但没有把 reference 路径包装成生产 same-decision GPU Evidence，也没有宣称最终阈值已经完成 GPU 标定。
