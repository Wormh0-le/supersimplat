# SuperSimPlat AI Select — Final Spec v1.2

**文档状态：Historical — superseded by Final Spec v1.3 on 2026-07-30.**

The current normative specification is:

- [`ai-select-final-spec-v1.3.md`](./ai-select-final-spec-v1.3.md)

Final Spec v1.2 consolidated the earlier Route-B-first architecture, including a generic acquisition backend registry, ProposalSet/Decision layers, adaptive sparse planning, and future sequence extension seams. ADR 0016 and Final Spec v1.3 subsequently replaced those current requirements after the static segmentation path was corrected to use the official SAM 3 Image instance interface and the v1 product was reduced to its required Prompt, geometry, and per-View Mask workflow.

The complete former v1.2 text remains available in repository history. It must not be used as an active implementation or closure source.
